# 📘 Practical Assignment 1: Introduction to R and Posit Cloud

## Objective

This practical assignment introduces students to **R** and **Posit Cloud**. The aim is to understand what R is, explore the Posit Cloud platform, and learn how to create and organize a basic R project.

No programming experience is required for this assignment.

---

# Learning Outcomes

By the end of this practical, students should be able to:

* Explain what R is and its uses in data analysis.
* Describe the purpose of Posit Cloud.
* Create a Posit Cloud account.
* Navigate the Posit Cloud interface.
* Create a new project (workspace).
* Upload files into a project.
* Create and open an R script.
* Capture evidence of each completed task.

---

# Assignment Instructions

## Task 1: Research R (2 Marks)

Research and answer the following questions:

1. What is R?
2. What is R used for?
